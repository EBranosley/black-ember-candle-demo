# Black Ember Co. Candle Website Demo

A Vite + React + Tailwind one-page website demo for a masculine limited-batch candle brand.

## Run in Cursor

1. Unzip this folder.
2. Open the folder in Cursor.
3. Open the terminal in Cursor.
4. Run:

```bash
npm install
npm run dev
```

5. Open the local URL Vite gives you, usually:

```txt
http://localhost:5173
```

## Image location

The candle images are already included here:

```txt
public/images/candles/
```

The website uses these paths:

```txt
/images/candles/black-ember.png
/images/candles/ironwood.png
/images/candles/the-stoic.png
/images/candles/midnight-leather.png
```
